Prevalence-based filtering

Features that show up in only a few samples may not represent real biological diversity but rather PCR/sequencing errors (such as PCR chimeras) or reagent contaminants.

Alpha diversity

“Alpha-diversity is the diversity in a single ecosystem or sample. The simplest measure is richness, the number of species (or OTUs) observed in the sample. Other metrics consider the abundances (frequencies) of the OTUs, for example to give lower weight to lower-abundance OTUs.” - Robert Edgar

Essentially, alpha diversity measures within-sample diversity across treatments. It is used to evaluate richness and abundance of microbial communities.

Initial plot: Use the phyloseq library to investigate the alpha diversity measure of each sample across the three treatment groups. Note that we will only use a subset of these measures (explained in further detail below).

🧮 Calculate alpha diversity

There are many different measures of alpha diversity: - Observed: The actual number of unique ASVs in a sample. Measures taxonomic richness. - ACE: Abundance-based coverage estimator. Based on the abundance of species and estimates the no. of additional species that are likely to be present but have not been observed. - Shannon: Takes into account both species richness and species evenness. It is calculated based on the logarithm of the relative abundances of species in a community. - Simpson’s Diversity Index: Takes into account the number of species present, as well as the relative abundance of each species. 1 = infinite diversity, 0 = no diversity. Measures dominance (i.e., evenness) - Fisher: Takes into account both the number of species (species richness) and the evenness of their distribution. - Chao1: Estimates the true number of species (species richness) in a community or sample, especially when some species are rare and may not be observed in the sample. It takes into account both the number of observed species and the number of rare or singleton species to provide an estimate of total species richness.

# ------------------------------------------------------------
# 2. Function for composition plots
# ------------------------------------------------------------

make_tax_composition_plot <- function(ps_obj,
                                      tax_rank = "Phylum",
                                      top_n = 10,
                                      x_var = "sample",
                                      facet_var = "treatment") {
  
  # Agglomerate taxa at selected rank
  ps_glom <- tax_glom(ps_obj, taxrank = tax_rank, NArm = FALSE)
  
  # Convert to long format
  tax_df <- psmelt(ps_glom)
  
  # Rename missing/unclassified taxa
  tax_df[[tax_rank]] <- as.character(tax_df[[tax_rank]])
  tax_df[[tax_rank]][is.na(tax_df[[tax_rank]]) | tax_df[[tax_rank]] == ""] <- "Unclassified"
  
  # Identify most abundant taxa
  top_taxa <- tax_df %>%
    group_by(.data[[tax_rank]]) %>%
    summarise(mean_abundance = mean(Abundance, na.rm = TRUE), .groups = "drop") %>%
    arrange(desc(mean_abundance)) %>%
    slice_head(n = top_n) %>%
    pull(.data[[tax_rank]])
  
  # Collapse low-abundance taxa into Other
  tax_df <- tax_df %>%
    mutate(
      Taxon = ifelse(.data[[tax_rank]] %in% top_taxa,
                     .data[[tax_rank]],
                     "Other"),
      Taxon = factor(Taxon)
    )
  
  # Order taxa by mean abundance, keeping Other last
  tax_order <- tax_df %>%
    group_by(Taxon) %>%
    summarise(mean_abundance = mean(Abundance, na.rm = TRUE), .groups = "drop") %>%
    arrange(desc(mean_abundance)) %>%
    pull(Taxon)
  
  tax_order <- c(setdiff(tax_order, "Other"), "Other")
  
  tax_df$Taxon <- factor(tax_df$Taxon, levels = rev(tax_order))
  
  # Plot
  ggplot(tax_df, aes(x = .data[[x_var]], y = Abundance, fill = Taxon)) +
    geom_bar(stat = "identity", width = 0.95) +
    facet_grid(
      cols = vars(.data[[facet_var]]),
      scales = "free_x",
      space = "free_x"
    ) +
    scale_y_continuous(
      labels = percent_format(accuracy = 1),
      expand = c(0, 0)
    ) +
    labs(
      x = "Samples",
      y = "Relative abundance",
      fill = tax_rank
    ) +
    theme_bw(base_size = 14) +
    theme(
      panel.grid = element_blank(),
      axis.text.x = element_blank(),
      axis.ticks.x = element_blank(),
      axis.title = element_text(face = "bold", colour = "black"),
      axis.text.y = element_text(colour = "black"),
      strip.text = element_text(face = "bold", colour = "black"),
      strip.background = element_rect(fill = "white", colour = "black"),
      legend.title = element_text(face = "bold", colour = "black"),
      legend.text = element_text(colour = "black"),
      legend.position = "right"
    )
}

# ============================================================
# Beta diversity: PCoA (CLR-transformed data)
# ============================================================

# ------------------------------------------------------------
# 1. CLR transformation
# ------------------------------------------------------------

ps_clr <- microbiome::transform(ps_NB, "clr")

# ------------------------------------------------------------
# 2. Distance matrix (Aitchison = Euclidean on CLR)
# ------------------------------------------------------------

clr_mat <- as(otu_table(ps_clr), "matrix")

# Ensure taxa are columns
if (taxa_are_rows(ps_clr)) {
  clr_mat <- t(clr_mat)
}

clr_dist <- dist(clr_mat, method = "euclidean")

# ------------------------------------------------------------
# 3. PCoA
# ------------------------------------------------------------

pcoa_res <- cmdscale(clr_dist, eig = TRUE, k = 2)

# Extract coordinates
pcoa_df <- as.data.frame(pcoa_res$points)
colnames(pcoa_df) <- c("PCoA1", "PCoA2")

# ------------------------------------------------------------
# 4. Add metadata
# ------------------------------------------------------------

meta_df <- data.frame(sample_data(ps_clr))

pcoa_df <- pcoa_df %>%
  mutate(
    Sample = rownames(pcoa_df)
  ) %>%
  left_join(
    meta_df %>% rownames_to_column("Sample"),
    by = "Sample"
  )

# Format treatment
pcoa_df$treatment <- factor(
  pcoa_df$treatment,
  levels = c("C", "L", "H"),
  labels = c("Control", "Low", "High")
)

# ------------------------------------------------------------
# 5. Variance explained
# ------------------------------------------------------------

eig_vals <- pcoa_res$eig

var_explained <- eig_vals / sum(eig_vals)

pc1_var <- round(var_explained[1] * 100, 1)
pc2_var <- round(var_explained[2] * 100, 1)

# ------------------------------------------------------------
# 6. Plot
# ------------------------------------------------------------

p_pcoa <- ggplot(pcoa_df, aes(x = PCoA1, y = PCoA2, colour = treatment)) +
  geom_point(size = 3, alpha = 0.8) +
  
  # Ellipses (visual grouping only)
  stat_ellipse(
    aes(group = treatment),
    type = "t",
    linetype = 2,
    linewidth = 0.8
  ) +
  
  scale_colour_manual(values = c(
    "Control" = "#1b9e77",
    "Low" = "#d95f02",
    "High" = "#7570b3"
  )) +
  
  labs(
    x = paste0("PCoA1 (", pc1_var, "%)"),
    y = paste0("PCoA2 (", pc2_var, "%)"),
    colour = "Treatment"
  ) +
  
  theme_bw(base_size = 14) +
  theme(
    panel.grid = element_blank(),
    axis.title = element_text(face = "bold", colour = "black"),
    axis.text = element_text(colour = "black"),
    legend.title = element_text(face = "bold"),
    legend.position = "right"
  )
